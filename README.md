# FleetManager

A simple web app using ASP.NET Core MVC to manage fleet travelling distances. 
The app will allow users to upload a photo and odometer readings, with downloadable reports in Excel format.

App is a work in progress, currently in early development see roadmap below for planned features.

Roadmap:
- [ ] User authentication and registration
- [X] Database connection
- [ ] User roles and permissions
- [ ] CRUD operations for users and fleet data
- [ ] Odometer reading input and storage
- [ ] Photo upload functionality
- [ ] Excel report generation and download
- [ ] UI improvements and responsive design
